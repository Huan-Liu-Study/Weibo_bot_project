一、数据采集层

为确保判定时效性，系统实施了“极简异步直达”的二次抓取策略 (v1.5.0)：

  • 并行解析 (Scrapy)：仅提取核心帖子文本与转评赞数量，剥离了一切不入模的冗余数据（如：发布地 IP、文章长链、精准地理坐标等），消灭了导致卡顿的同步阻塞。
  • 无头扩充 (Ajax 协程)：拿到核心名单后，由 asyncio + aiohttp 协程池瞬时回填用户的 粉丝数、历史发帖、V认证 等构建画像的必需要素。
  • 效率跃升：单条数据的全链路（抓取+画像重建）处理速度比旧版提升近 300%。

二、核心特征工程 (9 维)

系统精简了特征集，仅保留与 Random Forest 模型 强相关的 9 个核心维度。移除粉关比、缺省头像等噪音特征，增强泛化能力。

#特征名计算方法类型
1daily_post_rate近 20 条帖子数 / 时间跨度天数; 上限 50; log1p 缩放行为
2human_likeness_score词汇丰富度x0.4 + 主观词密度x0.3 + 复句复杂度x0.3语义
3exclamation_density(! + ！) 出现次数 / 文本总长度内容
4is_random_name昵称含 5 位以上连续数字 = 1账号
5engagement_count近 20 条原创帖的 (转+评+赞) 平均值; 最低兜底 1.0社交
6is_verified认证字段含 "V" 或 "认证" = 1信任
7sentiment_scoreSnowNLP 朴素贝叶斯（截取前 100 字符）; 0~1情感
8topic_diversity(独立话题数 + 无标签帖数) / 总帖数; 上限 1.0内容
9post_interval_variance近 20 条帖时间间隔（小时）的标准差; log1p 缩放时序

三、模型训练与推断

模型采用 RandomForestRegressor（scikit-learn），核心超参数：

  • n_estimators = 150（150 棵并行决策树）
  • max_depth = 8（限制树深，防止过拟合单一特征）
  • max_features = 'sqrt'（每棵树仅使用 sqrt(9) = 3 个特征，强制学习多维组合）
  • random_state = 42（确保可复现性）

训练数据：1300+ 条人工标注样本，采用 5 档连续评分体系（0.0 / 0.25 / 0.5 / 0.75 / 1.0），排除机器自动标注的数据，仅从人类专家判断中学习。

推断过程：输入 9 维特征向量 → 模型输出 0~1 连续可疑度分数（model_confidence）。

四、可疑度评分系统（加权规则）

系统并行运行一套基于用户标注体感校准的加权规则评分，作为模型的互补：

优先级特征权重阈值逻辑
高发帖间隔方差0.25log < 0.41 = 1.0, < 1.10 = 0.7, < 1.79 = 0.3
高日均发帖率0.25log > 3.93 = 1.0, > 3.04 = 0.7, > 2.40 = 0.4
高平均互动量0.25= 0 则 1.0, < 0.69 = 0.7, < 1.6 = 0.3
中数字乱码名0.15含5位连续数字 = 1.0, 否则 0
低感叹号密度0.10> 0.08 = 1.0, > 0.04 = 0.5

新闻媒体豁免：经 verified_reason 字段匹配 17 个媒体关键词后，可疑度 x0.3 衰减。

五、红旗否决机制 (Red Flag Override)

即使模型整体打分偏低，若以下任一硬性条件触发，可疑度将被强制提升至 ≥ 0.55：

  1. 发帖间隔方差 (log1p) ≤ 0.69 — 约等于 log1p(1)，即几乎等间隔发帖
  2. 日均发帖率 (log1p) ≥ 3.93 — 约等于 log1p(50)，日均 50 帖以上
  3. 话题多样性 ≤ 10%，且非默认值，即长期刷单一话题

六、分数融合与最终判定

最终可疑度通过加权融合生成：

  • 当模型可用时：最终分 = 20% x 规则分 + 80% x 模型分
  • 当模型不可用时：最终分 = 100% 规则分

融合后执行红旗否决与媒体豁免修正。最终判定阈值：≥ 0.7 判定为疑似水军。

单用户检测模式下，可疑度映射为 5 档标签：0(正常) / 1(偏低) / 2(中等) / 3(偏高) / 4(极高)。
