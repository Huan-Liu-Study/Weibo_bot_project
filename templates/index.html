一、数据采集层

系统基于 Scrapy 分布式爬虫框架，通过子进程自动唤醒终端执行 scrapy crawl search。采集前自动覆写 settings.py 中的关键词、采样深度和日期范围（最近 7 天）。

采集完成后，系统通过 aiohttp 异步并发（比同步快 5-10 倍）请求微博 Ajax API，批量获取每个独立用户的：

  • 用户画像：粉丝数、关注数、发帖总数、注册时间、个人简介、认证理由
  • 近 20 条博文时间线：发帖时间戳、转评赞数据、话题标签
  • 反爬策略：Cookie 统一从 settings.py 读取，动态 Referer + User-Agent 随机化

二、特征工程 (15 维)

系统从原始数据中提取 15 个核心维度，覆盖账号属性、行为模式和语义三大层面。其中 9 维作为模型输入特征。

#特征名计算方法入模

2daily_post_rate近 20 条帖子数 / 时间跨度天数; 上限 50; log1p 缩放Yes
3human_likeness_score词汇丰富度x0.4 + 主观词密度x0.3 + 复句复杂度x0.3Yes
4exclamation_density(! + ！) 出现次数 / 文本总长度Yes
5link_count博文中 http(s):// 的正则匹配数量—
6is_default_avatar头像 URL 含 "default" 或缺少 "tvax/tva" = 1—
7is_random_name昵称含 5 位以上连续数字 = 1Yes
8engagement_count近 20 条原创帖的 (转+评+赞) 平均值; 最低兜底 1.0Yes
9is_verified认证字段含 "V" 或 "认证" = 1Yes
10sentiment_scoreSnowNLP 朴素贝叶斯（截取前 100 字符）; 0~1Yes
11post_hour发帖时间戳提取小时数 (0-23)—
12desc_len个人简介字数 len(description)—
13topic_diversity(独立话题数 + 无标签帖数) / 总帖数; 上限 1.0Yes

注："入模 Yes" 标记的 9 项作为 RandomForest 模型的输入特征向量；其余 6 项用于规则评分或前端展示。

三、模型训练与推断

模型采用 RandomForestRegressor（scikit-learn），核心超参数：

  • n_estimators = 150（150 棵并行决策树）
  • max_depth = 8（限制树深，防止过拟合单一特征）
  • max_features = 'sqrt'（每棵树仅使用 sqrt(9) = 3 个特征，强制学习多维组合）
  • random_state = 42（确保可复现性）

训练数据：1300+ 条人工标注样本，采用 5 档连续评分体系（0.0 / 0.25 / 0.5 / 0.75 / 1.0），排除机器自动标注的数据，仅从人类专家判断中学习。

推断过程：输入 9 维特征向量 → 模型输出 0~1 连续可疑度分数（model_confidence）。

四、可疑度评分系统（加权规则）

系统并行运行一套基于用户标注体感校准的加权规则评分，作为模型的互补：

优先级特征权重阈值逻辑
高发帖间隔方差0.20log < 0.41 = 1.0, < 1.10 = 0.7, < 1.79 = 0.3
高日均发帖率0.18log > 3.93 = 1.0, > 3.04 = 0.7, > 2.40 = 0.4
高平均互动率0.18= 0 则 1.0, < 0.69 = 0.7, < 1.6 = 0.3
中数字乱码名0.10含5位连续数字 = 1.0, 否则 0
中默认头像0.08是默认 = 1.0, 否则 0
低粉关比0.08< 0.01 = 1.0, < 0.05 = 0.6, < 0.1 = 0.3
低外链数量0.06> 3 = 1.0, > 1 = 0.5, = 1 则 0.2
低感叹号密度0.04> 0.08 = 1.0, > 0.04 = 0.5

新闻媒体豁免：经 verified_reason 字段匹配 17 个媒体关键词后，可疑度 x0.3 衰减。

五、红旗否决机制 (Red Flag Override)

即使模型整体打分偏低，若以下任一硬性条件触发，可疑度将被强制提升至 ≥ 0.55：

  1. 发帖间隔方差 (log1p) ≤ 0.69 — 约等于 log1p(1)，即几乎等间隔发帖
  2. 日均发帖率 (log1p) ≥ 3.93 — 约等于 log1p(50)，日均 50 帖以上
  3. 话题多样性 ≤ 10%，且非默认值，即长期刷单一话题

六、分数融合与最终判定

最终可疑度通过加权融合生成：

  • 当模型可用时：最终分 = 40% x 规则分 + 60% x 模型分
  • 当模型不可用时：最终分 = 100% 规则分

融合后执行红旗否决与媒体豁免修正。最终判定阈值：≥ 0.7 判定为疑似水军。

单用户检测模式下，可疑度映射为 5 档标签：0(正常) / 1(偏低) / 2(中等) / 3(偏高) / 4(极高)。
