由于微博风控严格，您必须主动提供自己有效的网页版 Cookie 作为调用通道才能开启数据检测，否则所有检测引擎均无法获取到任何公开数据。

**如何获取：**
1. 在电脑浏览器新标签页登录 [weibo.com](https://weibo.com)
2. 按 **F12** 打开开发者工具，切换到 **Network (网络)** 面板
3. 随便搜个东西或刷新页面，在下方列表中随便点击一层请求（如 `mbuild` 或 `search`）
4. 在右侧查找到 **Request Headers** 下方的 `cookie:`，将其后面那一长串英文字符完整复制并粘贴到下方的输入框内
